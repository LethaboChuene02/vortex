# Installing pfSense Router

The pfSense Router works at Layer 3 on the OSI model or the Internet Layer. This will be used to:
1. Assign IP addresses to hosts using DHCP
2. Help hosts acceess the DNS server and connect to the ```vortex.local``` domain.
3. Create ACLs, to permit, deny or block certain sites and permissions. This will allow content filtering
